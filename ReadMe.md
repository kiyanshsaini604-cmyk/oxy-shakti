# Oxy Shakti

### AI-Powered Decentralized Emergency Intelligence Network

Oxy Shakti is a futuristic emergency intelligence platform built using IoT, AI, and Sui blockchain technology.

The system uses ESP32-based decentralized field nodes to monitor environmental threats such as gas leakage and abnormal temperature spikes in real time.

AI-powered threat analysis generates emergency recommendations while critical alerts are stored immutably on the Sui blockchain.

---

# 🌍 Problem

During disasters and emergency situations:

- Centralized communication systems can fail
- Emergency response becomes delayed
- Critical environmental data is often inaccessible
- Real-time coordination becomes difficult

Oxy Shakti aims to solve this by creating a decentralized emergency monitoring and intelligence infrastructure.
